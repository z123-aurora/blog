落点 ③ ｜ MCP 在 Trae 的哪里配置 —— 入口、落盘、以及它到底解决了什么

左：配置入口与 JSON 写法；右：本机真实存在的落盘目录与运行时日志路径
配置入口（图形界面）与配置格式（JSON）
⚙ Trae › 设置 › MCP › 添加 MCP 服务器 不同版本入口略有差异：AI 侧栏 → 智能体 → MCP 
{
  "mcpServers": {
    "fetch": {                       // 本地进程型（stdio）
      "command": "npx",
      "args": ["-y", "mcp-server-fetch"]
    },
    "blog-docs": {                   // 远程服务型（HTTP/SSE）
      "url": "https://mcp.example.com/sse",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
stdio 型给 command + args（Trae 负责拉起进程）；HTTP 型给 url + headers。添加成功后，该服务器提供的每个工具都会出现在 Agent 的可调用清单里。
