LAYER 01
模型层
Model

LAYER 02
Agent 层
Agent
把「想」变成「做」：拆解目标、调用工具、看结果、再修正。
这一层在做什么

循环：计划 → 行动 → 观察 → 反思。它决定了「一次任务能不能无人值守跑完」，而不只是答一句话。

在博客里的落点

一次重构任务内完成：读代码 → 列 22 项 → 改 9 个文件 → 跑 70 条测试 → 产出 REFACTORING.md，中途不换人。

可核对证据

project_memory.md 的 Lessons Learned
LAYER 03
能力层
Capability
模型之外的「手脚」：文件、终端、浏览器、图像、MCP、Git、云。
这一层在做什么

MCP 把每一项外部能力展开成一个有名字、有参数的工具，Agent 靠工具名调用——这是「会说」和「能干」的分界线。
